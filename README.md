# AI Resume Analyzer (Streamlit)

## Overview

This project is a Resume Analyzer built using Streamlit. It evaluates a given resume against a job description and calculates a match score along with an ATS score.

---

## Features

* Upload resume (PDF)
* Input job description
* Input required skills
* Calculate Match Score
* Calculate ATS Score
* Display evaluation metrics:

  * Keywords
  * Skills
  * Experience
  * Education
  * Projects
  * Certifications
  * Formatting
  * Soft Skills
  * Achievements

---

## Tech Stack

* Python
* Streamlit
* Natural Language Processing

## How to Run

1. Install dependencies
   pip install -r requirements.txt

2. Run the application
   python -m streamlit run app.py
